# P2P Energy Trading Platform - Capstone Project

A blockchain-based peer-to-peer energy trading platform enabling prosumers to sell surplus solar energy directly to consumers.

## Project Structure

```
energy-trading-platform/
├── frontend/     (React + Vite)
├── backend/      (Node.js + Express)
├── contracts/    (Solidity + Hardhat)
```

## Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Runs on http://localhost:5173

### Backend
```bash
cd backend
npm install
npm run dev
```
Runs on http://localhost:5000

### Smart Contracts
```bash
cd contracts
npm install
npx hardhat compile
```


## Technology Stack
- **Frontend**: React, Vite, Tailwind CSS, Ethers.js, MetaMask
- **Backend**: Node.js, Express, MongoDB, Mongoose
- **Blockchain**: Solidity, Hardhat, Polygon Amoy Testnet
- **Deployment**: Vercel (frontend), Railway (backend)
